# ECHO — Quantum Investigation

**Project:** Entangled Minds: The Quantathon  
**Team:** Qubits Qrew, NED University

## Overview

This project investigates the fictional ECHO quantum experiment using Python and Qiskit in Google Colab.

## Modules Completed

- **Module 01 — The Gatekeeper:** Quantum gates, measurement outcomes, and bit-pattern preparation.
- **Module 02 — The Honest Coin:** Quantum coin probabilities and analysis of the recovered seed circuit.
- **Module 03 — The Two Observers:** Quantum entanglement, classical correlations, and measurement-basis comparisons.
- **Module 05 — The Damaged Message:** Majority-vote decoding, error correction, and limitations of repetition coding.

## Tools Used

- Python
- Qiskit
- Qiskit Aer
- Google Colab
- NumPy

## Main Conclusion

The simulated experiments demonstrate that correlated measurement outcomes alone do not establish a faster-than-light messaging channel. The recovered seed circuit is biased, and the damaged classical message can be decoded using majority voting under the stated error assumption.

The available evidence does not establish who caused the events in the fictional case.

## How to Run

1. Download `ECHO_Investigation_Solved.ipynb`.
2. Open it in Google Colab.
3. Run the cells from top to bottom.
4. Read the Markdown explanations and investigation conclusion.
